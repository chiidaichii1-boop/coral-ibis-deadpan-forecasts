A single-line weather forecast for Fogmouth, a city that does not exist,
delivered deadpan: 8 degrees and drizzle, with fog so thick the lighthouse
has filed a formal complaint with the harbour board.

`main.py` (Python 3 standard library only) writes the line to
`$MAKEFUN_OUTPUT_DIR/entry.txt`.
